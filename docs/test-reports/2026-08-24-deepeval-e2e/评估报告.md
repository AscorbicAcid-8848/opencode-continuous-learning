## D. 切换到真实 LLM 评分

设置 `OPENAI_API_KEY` 后即可运行真实 DeepEval 评估：

```bash
export OPENAI_API_KEY="sk-..."
bun test ./evals/plugin-eval.test.ts
```

`plugin-eval.test.ts` 使用 DeepEval 的 3 个指标：
- `AnswerRelevancyMetric`（回答相关性，LLM-as-judge）
- `FaithfulnessMetric`（忠实度，从 context 提取 truth 再逐 claim 判断）
- `GEval`（自定义准则评分：记忆作用域正确性 + 安全过滤有效性）

也支持其他 judge model：

```bash
# 使用 Anthropic 作为 judge
npx deepeval set-anthropic --model claude-sonnet-4-5
```
